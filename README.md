# 超级TERM (superterm)

> 打开就可以使用完整 root shell 的最高权限终端。

## 简介

超级TERM（superterm）是一个最高权限终端应用，打开即可使用完整 root shell。
应用内的 DroidApp 即为文件源码，随仓库一并提供。

## 特性

- 打开即用，内置完整 root shell
- 最高权限终端环境
- 源码位于 `DroidApp/` 目录
- 仅需被管理器授权即可使用，无需额外环境依赖

## 目录结构

```
superterm/
├── DroidApp/        # 应用文件源码
├── README.md        # 项目说明
└── LICENSE          # GNU 通用公共许可证
```

## 使用方式

1. 将应用安装到设备
2. 在权限管理器中授予授权
3. 打开应用即可进入完整 root shell
